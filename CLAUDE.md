## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Design system

- Tokens, component classes and keyframes live in `src/styles/global.css`. Use them; never add new colours, fonts or border-radius.
- Chamfered components put their shape on clipped see (`.clip-cut`).
- All visible copy is Spanish, in LightSphere's voice. Unknown facts stay as `[PRECIO]`, `[DIRECCIÓN]`, etc.
